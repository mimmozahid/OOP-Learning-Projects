# Restaurant Management System

A console-based restaurant management application built in Python using object-oriented programming principles. The system supports both customer and admin workflows, enabling menu browsing, order placement, bill payment, employee management, and menu administration.

## Overview

This project simulates a small restaurant operation where:
- Customers can view the menu, add items to their cart, review their order, and pay the bill.
- Admins can add new menu items, remove items, and manage employee records.

The application is designed as a simple, educational project to demonstrate OOP concepts such as classes, inheritance, encapsulation, and object interaction.

## Features

### Customer Features
- Register as a customer
- View restaurant menu
- Add food items to the cart
- View cart details
- See total bill amount
- Pay bill

### Admin Features
- Add new food items to the menu
- Remove food items
- View all menu items
- Add new employees
- View employee list

## Tech Stack

- Python 3.x
- Object-Oriented Programming (OOP)
- Console-based user interface
