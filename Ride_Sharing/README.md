# Ride Sharing System

A Python-based Object-Oriented Programming (OOP) ride-sharing management system designed to model a simple ride booking workflow between riders and drivers. The project demonstrates core OOP concepts such as inheritance, abstraction, encapsulation, and object relationships.

## Overview

This system allows a rider to request a ride, matches them with an available driver, calculates a fare based on the vehicle type, and tracks the ride lifecycle from start to destination. It is a lightweight academic project that simulates a ride-sharing platform using Python classes and simple console-based interaction.

## Features

- Rider registration and wallet management
- Driver registration and current location tracking
- Vehicle abstraction with different types:
  - Car
  - Bike
  - CNG
- Ride request creation
- Driver matching logic
- Fare calculation based on vehicle category
- Ride start and end processing
- Ride details display
